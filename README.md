# Design Skills

Reusable AI skills for design practitioners and teams, maintained by [Ashwarya Subhluxmi](https://github.com/ash-warya).

## Available skills

| Skill | What it helps with |
|---|---|
| [UX Roadmapping](skills/ux-roadmapping/SKILL.md) | Build and review outcome-based Now/Next/Future roadmaps, prioritize with evidence, explain tradeoffs and facilitate workshops. |

Each skill is a self-contained folder. You can install only the skills you want.

## Install UX Roadmapping in Codex

Paste this into Codex on your personal or work laptop:

```text
Use $skill-installer to install the skill at:
https://github.com/ash-warya/design-skills/tree/main/skills/ux-roadmapping
```

Then ask:

```text
Use $ux-roadmapping to turn my team's goals, research, requests and capacity into a Now/Next/Future roadmap.
```

Codex detects installed skills automatically. If it does not appear, start a new chat or restart Codex. Installation creates a local copy; updates in this repository do not automatically update an installed copy. Ask Codex to update it deliberately while preserving local customizations.

For repository-scoped use, copy the whole skill folder into `.agents/skills/ux-roadmapping/` in your project. For other assistants that support Agent Skills, use their supported installation location. The Markdown method and template can also be read directly without an assistant.

## What is included

- Skill instructions and discovery metadata
- A practical roadmapping method
- One-workshop and two-workshop agendas
- A visual Now/Next/Future chart by default, with an accessible text equivalent
- Role-specific staffing, effort ranges, elapsed-time estimates and capacity tradeoffs
- A reusable roadmap, evidence and decision-log template

No personal vault, account connection or original course files are needed. Bring your own team context; keep confidential research and actual team roadmaps in your approved work environment.
